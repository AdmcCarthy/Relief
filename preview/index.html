Land and sea floor for the places we map

The North Sea, Norwegian Sea, Barents Sea, NE Europe and the world, each framed once and drawn the same way, so a map of any of them looks like it belongs with the others.

The house style
  • Detuned: land held back at half strength, the sea floor on its own deep indigo ramp.
  • Relief: stepped classes, tinted by climate zone.
  • Bathymetry: a linear gradient.
  • No contours, no illumination, no coastline line.

This page needs WebGL 2, which this browser does not provide.

Examples

Each map is drawn on your GPU from one 16-bit elevation file. The first five are the shared regions; the last is the proof of concept the techniques page is built on.

What each region is made of

Each region is built from the best open source for every part of it, finest first and blended with a feathered seam. The example above is one texture averaged to a web-friendly cell; the zoom page shows the finest tiles. Norwegian land is Copernicus GLO-30: Kartverket's lidar terrain service is not open data and is not used.

How the examples are built

Data

Sources are open and merged per region by priority, finest first, with a feathered seam. The source plan is a JSON file other tools can read; the long-running build is a resumable script that plans before it fetches. See the research notes.

Style

Land classes (0, 50, 150, 300, 600, 1,000, 1,500, 2,000 m) take one of four ramps by climate zone (Köppen–Geiger, cross-blended over about 6 km). Depth is a continuous gradient on a wider, deeper ramp, so shelves and trenches both read.

Delivery

Heights are packed into a lossless WebP (height = −11,000 m + 16-bit value × 0.5 m). The shader does the colouring, so the style is a few uniforms. A whole-region texture stays under 8,192 px and about 10 MB, which sets how fine a region example can be.
